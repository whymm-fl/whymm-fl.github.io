关于

我是 whymm，一名 CTF 选手与安全研究者。这个博客用来存放比赛复盘、漏洞原理拆解、工具链笔记，以及那些「当时没想明白、后来终于想明白」的瞬间。

这里写什么

方向 内容
Web SQL 注入、SSTI、反序列化、SSRF、文件上传、WAF 绕过
Pwn 栈溢出、堆利用（tcache / fastbin / unsorted bin）、格式化字符串、沙箱逃逸
Crypto RSA 各类攻击、格攻击、ECC、哈希碰撞与古典密码
Reverse IDA / Ghidra 静态分析、脱壳、VM 保护、混淆对抗
Misc 流量分析、隐写、内存取证、编码链
Blockchain 智能合约漏洞、EVM 底层、链上事件追踪

我的原则

  • 可复现优先：每篇 Writeup 都尽量给出完整环境、完整 payload，而不是只贴一句 flag{...}。
  • 讲清「为什么」：能打通不稀奇，知道为什么能打通才算学会。
  • 记录踩坑：失败的尝试往往比成功的路径信息量更大。
