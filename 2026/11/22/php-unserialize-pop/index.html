一、PHP 基础知识

PHP 简单介绍

PHP（Hypertext Preprocessor）是一种广泛使用的开源服务器端脚本语言，尤其适用于 Web 开发。它的灵活性、易学性和强大的社区支持，让 PHP 成为开发动态网页和 Web 应用的首选语言之一。PHP 代码在服务器上执行，生成的 HTML 发送给客户端，从而实现网页的动态交互。它被广泛应用在各种 Web 项目中，包括内容管理系统、电子商务平台和社交媒体网站。

更多资料可以到网上查，入门看菜鸟教程就够。

二、PHP 序列化与反序列化

1. 核心语法 serialize（序列化）

序列化就是把对象转换成一个字符串。目的主要有两个：

  1. 把对象状态保存到文件或数据库里；
  2. 把对象进行远程传输（比如前后端交互时发送数据）。

拆开看这段字符串：

  • O 代表对象（Object）；如果序列化的是数组，这里就是 A；
  • 7 是类名的长度，即 example 有 7 个字符；
  • example 是类名；
  • 2 表示类里面有 2 个属性（变量）；
  • s 表示字符串（string），后面的数字是长度。

比如 s:5:"first";s:3:"one"; 表示属性名 first（5 个字符）和它的值 one（3 个字符）。private / protected 属性序列化后名字前面会多出不可见字符，这也是做题时经常要手改的地方。

3. 魔术方法

PHP 魔术方法是以 __ 开头的特殊方法（注意是两条下划线，不是一条）。它们在对象被创建、访问属性、调用不存在的方法、序列化等特定场景下自动触发，由 PHP 保留，必须按规定签名声明，多数要求为 public。

以下方法被官方认定为魔术方法：

方法 触发时机
__construct() 创建对象时
__destruct() 对象销毁时
__call() 调用不存在的对象方法
__callStatic() 调用不存在的静态方法
__get() 读取不可访问属性
__set() 写入不可访问属性
__isset() 对不可访问属性使用 isset()
__unset() 对不可访问属性使用 unset()
__sleep() serialize() 时触发
__wakeup() unserialize() 时触发
__serialize() PHP 7.4+ 新序列化机制
__unserialize() PHP 7.4+ 新反序列化机制
__toString() 对象被转成字符串时
__invoke() 对象被当作函数调用时
__set_state() var_export() 时触发

魔术方法一般就是 POP 链的漏洞点，可以自己在 VS Code 里码一遍看触发顺序。

5. 一些逃逸

str_replace("a", "b", $A) 用于字符替换：在 $A 中把前面的字符用后面的字符替换。当替换前后长度不一致时，序列化字符串里声明的长度就和实际内容对不上，多出来或少掉的部分就会被反序列化器当成新的属性去解析 —— 这就是字符串逃逸。

三、一些例题

1. ez_pop

简单分析：

  1. 看到 $_GET['wish']，可知我们可以构造 payload 后通过 GET 提交：题目网址?wish=构造的payload。
  2. append() 里的 include() 可以加载并执行另一个文件中的 PHP 代码，而代码最后一句写着 Try to See flag.php，说明目标是让 include() 读到 flag.php。
  3. 逆着推 POP 链：要触发 include()，需要先触发 __invoke()；而 Make_a_Change::__get() 里的 return $function(); 正好会「把属性当函数调用」，满足 __invoke() 的触发条件。要触发 __get()（访问不可访问的属性），就看 Road_is_Long::__toString() 里的 return $this->string->page; —— 它访问了 string 的 page 属性，只要让 string 指向 Make_a_Change，就会触发 __get()。而要触发 __toString()（对象被当字符串输出），Road_is_Long::__wakeup() 里那行 echo "You can Not Enter 2024"; 正好满足。

但 __wakeup() 和 __toString() 都在 Road_is_Long 里，同一个对象只能触发一次，所以要用两个 Road_is_Long：一个让 __wakeup() 触发 __toString()，另一个在 page 上被访问时提供属性，从而串成完整链条。
