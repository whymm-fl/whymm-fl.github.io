一、SQL 核心原理

SQL 注入是一种将恶意 SQL 代码插入用户输入并由数据库执行的攻击方式，可导致数据泄露、权限提升甚至删除数据库等严重后果。常见场景包括登录框、搜索框、URL 参数等，核心防御手段是使用参数化查询与严格输入验证。

SQL 注入的本质：用户输入的数据，被当作 SQL 语句的一部分执行。

二、SQL 注入的危害

  • 数据泄露：获取用户信息、密码、订单等敏感数据。
  • 权限提升：读到后台账号、用 into outfile 写文件，进一步执行系统命令拿下服务器。
  • 数据篡改：update、delete 被打进去，整张表甚至整个库都可能被清掉。
  • 绕过业务逻辑：登录校验、支付金额、管理员权限判断，都可能被一句 or 1=1 直接跳过。
